## mark scheme

### BASIC CONTENT FEATURES - Must Have (/20) 

- [ ] >= 2 Pages With sensible / interesting content.
- [ ] Correctly laid out page (header section correct, body correct)
- [ ] Basic tags used. (including)
  - [x] headings
  - [x] paragraphs
  - [ ] lists
  - [x] span
  - [x] div
- [ ] Basic css properties used. (including)
  - [x] font (family, size, colour, weight)
  - [x] background-color
  - [ ] border
  - [x] margin
  - [x] padding
- [x] Links Between pages
- [ ] Links To external sites
- [x] Images
- [ ] Tables

### BASIC DESIGN FEATURES - CCS (/10)

- [x] Good choice of fonts (use font-family property to change default formats) Important items stand out through use of size and colour
- [x] Good use of whitespace (paddings and margins &c) to create a well laid out balanced page
- [ ] Advanced css (including)
  - [x] Classes
  - [x] ID
  - [x] Pseudo-classes (:hover &c)
  - [x] Float / display

### ADVANCED FEATURES + DELIVERY - Could have (/10)

- [x] Nav Bar - Menu System on top of each page allowing the user to choose between pages easily
- [ ] Javascript - e.g. add a button that does something to your website when the user clicks on it. Must be relevant to your website
- [ ] Video (Youtube embed)
- [ ] Any other feature you have researched and worked out how to use. (Video &c, any css that you have had to research yourself in order to use)
  - [ ] PLUS 2 bonus marks if you have something I think is very difficult or needs alot of time to get right (like drop down menus with gradual drop)

### HTML Layout

- [ ] HTML well laid out
- [ ] easy to read
